# Source Notes

This repo separates three kinds of material:

- Official sources: TMR, Your Say, the Gumpi Master Plan, consultation summary and public government/open-data pages.
- Community evidence: 360 photos, hall-display photos and public-safe notes.
- Community proposals: design spectrum, simulation workflows, co-op capability transfer and Ballow Road links.

The current public photo data is intentionally rounded and labelled as not survey-grade. The original full-size images remain outside this public repo. The generated web assets are smaller WebP files with image metadata removed.

The next data step should be documented through `capture-log-template.md` before public publication.
